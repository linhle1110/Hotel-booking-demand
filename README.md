# Hotel-booking-demand
The project analyses the reservation data of a city hotel and a resort hotel from 2015 to 2017. The dataset contains over 20k historical hotel booking records with details like hotel type, booking behavior, customer profile, and distribution channel. The project uses Python and Power BI for data plotting and manipulation. 
This is the link to the dataset: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
